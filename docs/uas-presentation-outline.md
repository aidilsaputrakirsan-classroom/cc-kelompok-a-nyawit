# UAS Presentation Outline

Follow the suggested 5-7 slides:
1. Title — Project name, team, members
2. Problem & Solution — what the app solves
3. Architecture — mermaid diagram + components
4. Tech Stack & CI/CD — describe pipeline and deployment
5. Live Demo — scripted steps (register, login, CRUD, health)
6. Challenges & Lessons Learned
7. Team Contributions & Q/A

See `docs/` for deployment and API contract used in demo.
